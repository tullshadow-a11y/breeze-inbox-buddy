# Umbra Mail roadmap

- [ ] Side menu with Inbox, Sent, Drafts, Saved, Archive, Trash, Settings pages
- [ ] Compose internal notes / passphrase-encrypted messages, auto-saved drafts
- [ ] Search, filter and sort in every mailbox; star, archive, trash, restore
- [ ] Settings: refresh interval, sound, pop-ups, dark/light theme, accent colors, profile, JSON/CSV export, clear data
- [ ] Local persistence of settings, messages and drafts
- [ ] Stats widget: total received, session duration, storage health
