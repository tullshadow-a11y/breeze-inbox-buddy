# Umbra Mail

A modern, fully functional temporary email application built with React, TypeScript, and Tailwind CSS. Featuring a sleek Glassmorphism dark interface for secure and private temporary inbox management.

## Key Features

1. **Instant Generation:** Instantly generate a random temporary email address with a single click.
2. **Live Inbox:** A clean, real-time inbox section that displays incoming messages, subjects, times, and content dynamically.
3. **Quick Actions:** Convenient action buttons to refresh the inbox, copy the address, or delete the current email.
4. **Professional Empty States:** Clean and polished states when no messages are present.

## Tech Stack

* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS
* **Icons & UI:** Lucide React, Glassmorphism design
